# 💳 Sistema de Preços e Formas de Pagamento

Projeto desenvolvido em **Python** como exercício de lógica de programação e estruturas condicionais.

O programa calcula o valor final de um produto de acordo com a **forma de pagamento escolhida**, aplicando descontos, parcelamentos ou juros conforme a opção selecionada.

## 🎯 Objetivo

Desenvolver uma aplicação simples capaz de:

- Receber o preço de um produto;
- Permitir que o usuário escolha a forma de pagamento;
- Aplicar diferentes regras de desconto;
- Calcular valores de parcelas;
- Aplicar juros em determinados tipos de parcelamento;
- Apresentar o valor final da compra.

## 🛠️ Tecnologias

- Python 3
- PyCharm

## 📚 Conceitos praticados

- Entrada de dados com `input()`
- Conversão de tipos
- Operações matemáticas
- Estruturas condicionais (`if`, `elif`, `else`)
- Cálculo de porcentagens
- Cálculo de parcelamento
- Formatação de valores monetários

## ⚙️ Regras utilizadas

O programa trabalha com diferentes formas de pagamento:

| Forma de pagamento | Regra |
|---|---|
| Dinheiro/Cheque | 10% de desconto |
| Cartão à vista | 5% de desconto |
| Cartão em 2x | Valor original |
| 3x ou mais | Acréscimo de 20% |

O usuário também informa a quantidade de parcelas quando escolhe uma opção de parcelamento.

## 💻 Exemplo

```text
Valor do produto: R$1000

1- À vista no dinheiro/cheque
2- À vista no cartão
3- 2x no cartão
4- 3x ou mais no cartão

Qual a forma de pagamento escolhida: 1

O valor total a ser pago será de R$900.00
```
